# Online Library Management System

Student practice/demo project using Java, JDBC, MySQL, HTML and CSS.

## Features
- Add and view books
- Register members
- Issue and return books
- Track issue records

## Setup
1. Run `database/library.sql` in MySQL.
2. Add MySQL Connector/J to the Java classpath.
3. Change the MySQL password in `src/DBConnection.java`.
4. Compile and run `src/LibraryManagementSystem.java`.
5. Open `web/index.html` for the frontend demo.

This is a learning/demo project. The frontend and Java JDBC application are separate parts.
